### Task 1.2 - Identify hardware and software

| Item | Hardware or software | Software type (if applicable) | Purpose |
| --- | --- | --- | --- |
| Keyboard | Hardware | Not applicable | Input device used to type text and commands. |
| Trackpad | Hardware | Not applicable | Input device used to move the pointer, click and use gestures. |
| Display | Hardware | Not applicable | Output device that shows text, pictures and other information. |
| Camera | Hardware | Not applicable | Input device that captures images and video. |
| SSD | Hardware | Not applicable | Storage device that keeps files and programs when power is off. |
| Microphone | Hardware | Not applicable | Input device that captures sound. |
| Speakers | Hardware | Not applicable | Output devices that play sound. |
| VS Code | Software | Application software | Used to write and edit code and text files. |
| Safari | Software | Application software | Used to browse websites. |
| Terminal | Software | Utility software (system utility) | Provides a text interface for working with a shell and running commands. |
| Finder | Software | Utility software (system utility) | Helps browse and manage files and folders. |
| Notes | Software | Application software | Used to write, organize and save notes. |
| Python interpreter | Software | Programming tool | Runs Python code. |
| macOS | Software | Operating system software (system software) | Manages hardware and resources and provides services for applications. |

**Hardware** means the physical parts of a computer, such as its keyboard, display and SSD.

**Software** means the programs and instructions that tell a computer what to do.

**System software** manages the computer and supports other programs. The operating system is the main example. System utilities help users manage or work with the system.

**Application software** helps a user complete a task, such as writing a note, editing code or browsing a website.

**macOS is system software** because it manages resources such as memory, files and devices, and provides services that applications use. It is the operating system, rather than an application for one user task.

The Python interpreter is listed as a programming tool because it executes code. Terminal and Finder are listed as system utilities because they help users interact with the system.

### Task 1.3 - Computer systems around you

| System | Main purpose | One input | One output |
| --- | --- | --- | --- |
| ATM | Banking operations | PIN entered through a keypad | Transaction result on the screen |
| Smart TV | Digital entertainment | Remote control command | Video displayed on the screen |
| Gaming console | Running video games | Controller button press | Game visuals on the screen |

**ATM:** The ATM processes the entered PIN as part of checking access to the account. It communicates with the bank's system to process a requested transaction and shows the result on the screen.

**Smart TV:** The TV processes a remote control command, such as selecting a channel or video, and displays the selected content on its screen.

**Gaming console:** The console processes the controller input, updates the game according to its rules, and produces the game visuals shown on the screen.

These examples explain how everyday computer systems work. I did not record any hands-on tests of these systems for this mission.
