Repository name: `digital-detective-8427`. The suffix matches the last four USN digits, confirmed by the student. Full student details are omitted for privacy.

- Understand computer input, processing, output and storage.
- Practise Terminal commands and safe file management.

## Project organization

Each mission has its own folder and README. Missions 0–7 are complete. Mission 8 still contains a template. The [number converter](mission-05-numbers-data/number_converter.py) uses functions and while loops to convert decimal integers to binary and hexadecimal. The Mission 5 README also demonstrates Python's built-in `bin()` and `hex()` functions. Evidence folders hold privacy-safe screenshots or selected command output.

Each completed mission must have its own meaningful commit and verified push. The later mission templates belong to the setup scaffold and do not count as completed missions. Complete, document, commit, push and verify the current mission before starting the next.
